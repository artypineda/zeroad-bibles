# Free Bible versions

Public-domain Bible texts, ready to download into a Bible app. Each version's source licence page is listed in `catalog.json`.

- Only versions whose source lists them as public domain are included.
- Wording is not edited. Footnote markers and section headings are left out.
- No copyrighted versions are hosted here, and this repo doesn't accept files from app users.

This is a working list, not legal advice, and it is still awaiting legal review. If you believe something here shouldn't be, please open an issue and it will be looked at promptly.
